# Traccar для intraHouse

Плагин читает последнюю известную позицию трекера через REST API Traccar. Подходит для Teltonika и других трекеров, подключённых к Traccar. Один экземпляр поддерживает до трёх трекеров на одном сервере.

## Установка

1. На GitHub нажмите **Code → Download ZIP** или [скачайте ZIP исходников](https://github.com/apnagaev/intrahouse-traccar-plugin/archive/refs/heads/main.zip).
2. В панели сервера intraHouse откройте **Плагины → Import**, выберите ZIP и обновите Project Manager. Файлы `traccar.ih`, `manifest.json`, `index.js` и каталог `v5` находятся в корне исходников. Плагин использует Node.js 18+ и встроенный fetch.
3. Добавьте экземпляр Traccar. Введите базовый URL веб-сервера Traccar (например, `https://traccar.example.org`), токен аккаунта с доступом к трекеру, ID устройств через запятую (например `168,481,1169`) и интервал опроса. Каждый экземпляр имеет свой сервер, токен и список устройств.
4. В контекстном меню экземпляра добавьте **Набор каналов Traccar**, привяжите канал source_snapshot к строковому свойству с чтением и записью и запустите экземпляр.

Плагин использует `GET /api/positions`, который возвращает последние позиции устройств, доступных аккаунту. Экземпляр публикует позиции настроенных трекеров. Используйте HTTPS для передачи токена. В GitSync маскируйте поле `token`, если конфигурация проекта хранится в Git.

## Выбор показаний

Канал `source_snapshot` передаёт JSON. В авто каждое поле берётся из последней по `serverTime` точки, содержащей это поле. В ручном режиме приоритет получает выбранное устройство. Для переключения запишите JSON `{"mode":1}`. Значения 1–3 соответствуют порядку устройств, 0 включает авто. В `sources` указаны ID источников отдельных показаний.

В разделе «Каналы» добавьте набор готовых полей или отдельный канал. Для своего канала задайте название, путь из ответа Traccar (например `attributes.batteryLevel`) и привяжите его к свойству устройства. Значения полей сохраняют единицы Traccar. Массивы и объекты передаются строкой JSON.
